# リファクタ後スモークチェックリスト

大きめの分割やサービス化を行った後に、短時間で主要機能が壊れていないことを確認するためのチェックリストです。

## メイン画面

- アプリを起動できる。
- CSVファイルを選択して一覧に表示できる。
- フォルダー選択で複数CSVを読み込める。
- 最近使用したCSV、最近使用した出力先のドロップダウンが表示される。
- CSVフィールドの有効、必須、条件、種類、演算、値を編集できる。
- フィルター条件を変更するとプレビューが更新される。
- ページ全体表示で前へ、次へが動く。
- 1枚拡大表示で前へ、次へがタグ単位で動く。

## 出力

- PNG保存が指定した出力先に保存される。
- PDF保存が指定した出力先に保存される。
- PDF保存完了ダイアログが表示され、保存先を開く設定が保持される。
- 直接印刷のプリンタ選択ダイアログが表示される。
- 補正X、補正Y、印刷順、並び替え列の設定がプレビューや出力に反映される。
- 印刷対象確認ダイアログのオン/オフ設定が効く。

## レイアウトデザイナー

- レイアウトデザイナーを開ける。
- Elements、Properties、Canvas が表示される。
- CSV読み込み済みの場合、Preview Row にCSV行が表示される。
- Canvas上のテキスト要素をダブルクリックして編集できる。
- Enterで確定、Shift+Enterで改行できる。
- CSV列に紐づく値をCanvas下部の編集欄から変更できる。
- Save CSVでCSVへ保存できる。
- 画像追加、バーコード追加、色変更が動く。
- 拡大、標準、縮小ボタンでCanvas領域が変わる。

## タグファインダー

- タグファインダーを開くと検索値にフォーカスがある。
- 検索項目と保存列の前回設定が復元される。
- 検索で一致行が一覧表示される。
- trueのみ表示で保存列がtrueの行だけ表示される。
- 印刷枚数が1の場合は通常保存になる。
- 印刷枚数が2以上の場合は追加分のキューCSVが作成される。
- キューCSVをすべて削除できる。
- プレビュー表示のオン/オフが保持される。
- キューCSVのタグをレイアウトデザイナーで開こうとすると警告が出る。

## CSV重複整理 / CSVマージ

- 重複整理タブで検出、並び替え、適用ができる。
- キューCSVは重複整理対象から除外される。
- 引き継ぎ設定とコピー対象列の前回状態が復元される。
- CSVマージタブで親CSVを選び、プレビュー、実行ができる。
- マージ後に不要CSV、bakファイルをゴミ箱へ移動する設定が効く。
- キューCSVはCSVマージ対象から除外される。

## 設定

- 言語切り替えで主要メニュー、ボタン、ラベルが日本語/英語に切り替わる。
- 起動時CSV、起動時フォルダーの設定が保存される。
- 設定バックアップZIPを作成できる。
- 設定バックアップZIPをインポートできる。
- 設定ファイルの場所を開ける。
